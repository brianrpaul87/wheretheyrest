# Where They Rest

Official website repository for **Where They Rest Memorial Care**.

> Wherever you are, we care for where they rest.

Where They Rest helps families arrange respectful grave and memorial care when they cannot visit in person.

## Preliminary website

This repository contains a dependency-free static website built with:

- Semantic HTML
- Responsive CSS
- Lightweight vanilla JavaScript
- Local SVG brand and illustration assets

## Initial services

- Grave-marker and memorial cleaning
- Flower and tribute placement
- Seasonal visits
- Photo and condition updates
- Recurring memorial-care plans
- Cemetery and Authorized Memorial Steward partnerships

## Run locally

From the repository root:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Current limitations

This is a preliminary marketing site. The request form is deliberately non-transmitting until secure intake, privacy terms, service coverage, pricing, and contact channels are finalized.
